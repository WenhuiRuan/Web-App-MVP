# 最终五份议题与阵容样例

当前契约：CreateDiscussion + Participant。每份含 4 专家及 1 主持人；角色均为虚拟设定，不代表真人背书。前四份为开发代理按议题编写和复核的预设内容，第五份为实际 DeepSeek 生成且已复核的阵容。源码数据： [rosters.json](rosters.json)。不以五份阵容冒充五场完整真实讨论。

## 查看与导入

可直接阅读本页；项目根执行 `python -m scripts.final_samples` 校验。离线导入及启动方式见 [README](../../../README.md#数据库与样例)，必须先停止目标数据库所属服务。导入 READY，不生成或重放消息；再次导入跳过一致记录，冲突/写入失败整批回滚。首页从“已保存的讨论”进入阵容，点击确认才开始模型任务。
